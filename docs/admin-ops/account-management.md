# Account Management Stack Deployment

This guide is for Administrators SELF-HOSTING their organization's use of the 63Klabs Atlantis DevOps Platform.

It is recommended to begin your platform journey by using the 63Klabs provided infrastructure for a period of time before taking on the task of self-hosting.

Since self-hosted Atlantis DevOps Platforms are deployed using the Atlantis DevOps Platform, this also solves the chicken and egg problem.

## 63Klabs Atlantis DevOps Platform Administration Guide for Organizations

Follow and become familiar with [63Klabs Atlantis DevOps Platform Administration Guide for Organizations](https://github.com/63Klabs/atlantis-platform-admin).

At the very least, create a sandbox AWS Account and experiment, learn, and understand the configurations.

## Deploy your own

The administration guide provides brief instructions on setting up a self-hosted Atlantis DevOps Platform. If you follow best practices, are familiar with AWS resources and deployments, and spent time experimenting with Atlantis in a sandbox, then you should be good to go.

This repository contains both GitHub Actions and CodeBuild configurations for whichever deployment pipeline you use.
